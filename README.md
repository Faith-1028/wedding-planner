# 💍 我们的婚礼 · 备婚协同管理平台

温馨香槟风的私人交互式备婚协同管理网页，支持多人在线实时同步。

## ✨ 功能特性

- **登录系统 + 分级权限**：管理员（新人）完整操作权限，普通用户只读浏览
- **实时云端同步**：基于 Supabase，任意用户新增/修改/删除，所有在线页面自动刷新
- **全局消息弹窗**：管理员操作后，所有在线用户自动收到弹窗通知
- **完整操作日志**：永久记录所有变更行为，支持筛选和导出
- **移动端自适应**：电脑、手机浏览器完美适配

## 🚀 快速开始

### 方式一：预览模式（立即可用）

直接用浏览器打开 `index.html` 即可体验全部功能。

- 初始管理员账号：`wedding_admin`
- 初始密码：`Wedding2026!`

> ⚠️ 预览模式下数据保存在当前浏览器会话中，关闭页面后数据丢失。如需多人实时协同，请按下方步骤配置 Supabase。

### 方式二：配置 Supabase 云端同步（推荐）

#### 第 1 步：创建 Supabase 项目

1. 访问 [supabase.com](https://supabase.com) 注册并创建新项目
2. **区域建议选择「Singapore」**，国内访问速度更快
3. 等待项目初始化完成

#### 第 2 步：初始化数据库

1. 进入项目控制台，点击左侧「SQL Editor」
2. 点击「New query」
3. 打开本项目根目录的 `supabase-setup.sql` 文件，复制全部内容
4. 粘贴到 SQL Editor 中，点击「Run」执行
5. 确认所有表创建成功（左侧 Table Editor 可查看）

#### 第 3 步：获取 API 密钥

1. 进入项目「Settings → API」
2. 复制以下两个值：
   - **Project URL**（形如 `https://xxxxx.supabase.co`）
   - **anon public key**（一长串 JWT 格式的字符串）

#### 第 4 步：配置应用

1. 打开 `js/config.js` 文件
2. 填入你的 Supabase 信息：

```javascript
SUPABASE_URL: 'https://你的项目ID.supabase.co',
SUPABASE_ANON_KEY: '你的anon_key',
```

3. 保存文件，重新打开 `index.html`
4. 顶部不再显示「预览模式」提示条，说明已连接云端

#### 第 5 步：启用实时订阅

1. 进入 Supabase 控制台「Database → Replication」
2. 确认 `supabase_realtime` Publication 已包含所有表
3. （SQL 脚本已自动配置，通常无需手动操作）

### 部署上线

将整个项目文件夹部署到任意静态网站托管服务：

- **GitHub Pages**：上传到 GitHub 仓库，开启 Pages
- **Vercel / Netlify**：拖拽文件夹即可部署
- **腾讯云 / 阿里云 OSS**：上传文件，开启静态网站托管

## 👥 用户角色说明

| 角色 | 权限 |
|------|------|
| 超级管理员 | 新增/编辑/删除所有数据、用户管理、修改倒计时、查看日志 |
| 普通只读用户 | 浏览全部信息、复制清单文本，无法修改任何数据 |

### 创建新用户

1. 管理员登录后，进入「用户管理」
2. 点击「创建新账号」
3. 填写账号、姓名、密码、角色
4. 将账号密码告知对方（父母/伴郎伴娘）

## 🔒 安全说明

- 密码使用 SHA-256 哈希存储，不明文保存
- 权限控制在前端应用层实现
- RLS 策略设为允许 anon key 访问（因使用自定义认证体系）
- 如需更高安全性，可配合 Supabase Auth 使用

## 🛠 技术栈

- **前端**：HTML + CSS + JavaScript（纯原生，无框架依赖）
- **后端**：Supabase（PostgreSQL + Realtime）
- **CDN**：jsDelivr（Supabase JS SDK）
