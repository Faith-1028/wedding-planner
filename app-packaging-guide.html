方案一：PWA 渐进式应用（推荐 · 已部署）

PWA 是目前最轻量、最通用的打包方式。用户无需下载安装包，直接访问网址即可「安装」到桌面/手机主屏，体验接近原生 App。

已实现的 PWA 特性

  • 📦 可安装：添加到桌面/主屏后显示独立图标，全屏启动，无浏览器地址栏
  • 🔄 离线缓存：Service Worker 缓存所有静态资源，断网也能打开应用
  • 📱 自适应：桌面/平板/手机自动适配布局
  • 🎨 原生体验：自定义启动画面、主题色、应用图标
  • 🔔 快捷入口：桌面右键菜单可直达首页/宾客/流程等模块

电脑端安装方式（Chrome / Edge）

打开浏览器访问 https://faith-1028.github.io/wedding-planner/
地址栏右侧会出现 安装图标（⊕），或在菜单中选择「安装此应用」
点击安装，桌面会生成「备婚管家」快捷方式
双击图标即可像普通软件一样启动，无需再打开浏览器

安卓手机安装方式

用 Chrome 浏览器打开网址 https://faith-1028.github.io/wedding-planner/
点击浏览器菜单（⋮）→ 选择「添加到主屏幕」
确认安装，桌面会生成 App 图标

💡 微信内打开：微信内置浏览器不支持 PWA 安装，需点击右上角「⋯」→「在浏览器打开」，然后用 Chrome 安装。

方案二：Electron 桌面客户端（.exe 安装包）

Electron 将网页应用打包成原生桌面程序，用户可以下载 .exe 安装包，像普通软件一样安装使用。

项目结构

wedding-planner/
├── index.html          # 网页应用（已有）
├── css/                # 样式文件（已有）
├── js/                 # 脚本文件（已有）
├── icons/              # 应用图标（已生成）
├── manifest.json       # PWA 配置（已生成）
├── sw.js               # Service Worker（已生成）
└── desktop/            # ← Electron 桌面客户端
    ├── package.json    # 依赖与构建配置
    ├── main.js         # 主进程（窗口管理、菜单）
    ├── preload.js      # 预加载脚本
    └── dist/           # 构建输出（.exe 安装包）

构建步骤

确保已安装 Node.js 18+（下载地址：nodejs.org）
打开命令行，进入 desktop 目录： 
cd desktop
npm install
等待依赖安装完成（首次约 3-5 分钟）
开发调试模式运行： 
npm start
会打开桌面窗口，可直接预览应用
打包为 .exe 安装程序： 
# 安装版（推荐，带安装向导）
npm run build:nsis

# 便携版（免安装，单文件 exe）
npm run build:portable
构建完成后，在 desktop/dist/ 目录下找到 .exe 文件，即可分发给其他人员安装

打包产物说明

文件类型大小（预估）说明
备婚管家-Setup-1.0.0.exeNSIS 安装包~85MB双击安装，可选安装路径，创建快捷方式
备婚管家-便携版-1.0.0.exe便携版~85MB免安装，双击直接运行
⚠️ 注意：Electron 打包需要 Node.js 环境，需在本地电脑执行。构建过程会下载 Electron 运行时（约 80MB），首次构建稍慢。

方案三：Android APK 安装包

将网页应用打包为 Android 原生 .apk 文件，用户下载后直接安装到手机。

推荐方案：Capacitor（Ionic）

Capacitor 是 Ionic 团队开发的跨平台容器，可以将任意 Web 应用包装为原生 Android/iOS 应用。

操作步骤

安装依赖（需 Node.js）： 
npm install @capacitor/core @capacitor/cli
npm install @capacitor/android
npx cap init 备婚管家 com.wedding.planner
配置 capacitor.config.json： 
{
  "appId": "com.wedding.planner",
  "appName": "备婚管家",
  "webDir": ".",
  "server": {
    "url": "https://faith-1028.github.io/wedding-planner/"
  }
}
生成 Android 工程： 
npx cap add android
npx cap sync
用 Android Studio 打开 android/ 目录
在 Android Studio 中点击 Build → Build APK，生成 .apk 文件
将 .apk 发给伴郎/亲友，手机安装即可

替代方案：PWABuilder（最简单）

  1. 访问 https://www.pwabuilder.com/
  2. 输入网址 https://faith-1028.github.io/wedding-planner/
  3. 点击「Build My PWA」→ 选择 Android
  4. 下载生成的 .apk 安装包

PWABuilder 会自动读取 PWA manifest 和 service worker，生成完整的 Android 安装包，无需配置开发环境。

🔄 多人协同与数据共享原理

无论使用哪种打包方式（PWA / Electron / APK），多人协同机制完全一致，因为所有数据都存储在 Supabase 云端数据库。

协同架构图

                    ┌─────────────────────┐
                    │   Supabase 云端      │
                    │   (PostgreSQL 数据库) │
                    │                     │
                    │  ├─ guests (宾客)    │
                    │  ├─ timeline (流程)  │
                    │  ├─ budget (预算)    │
                    │  ├─ vehicles (车辆)  │
                    │  └─ ... 16+ 张表     │
                    │                     │
                    │  Realtime 实时推送    │
                    └──────┬──────┬───────┘
                           │      │
              ┌────────────┘      └────────────┐
              │                                │
    ┌─────────┴─────────┐          ┌──────────┴──────────┐
    │  用户 A (管理员)    │          │  用户 B (普通成员)   │
    │  电脑端 PWA/Electron│          │  手机端 PWA/APK     │
    │  ↓ 修改数据         │  ←推送→  │  ↑ 实时收到更新      │
    │  ↓ 写入 Supabase   │          │  ↓ 页面自动刷新      │
    └───────────────────┘          └─────────────────────┘

数据协同工作流程

用户登录：所有人使用分配的账号密码登录（admin 管理员 / viewer 普通成员）
数据存储：所有操作（新增/编辑/删除）直接写入 Supabase 云端数据库，不存储在本地
实时推送：Supabase Realtime 监听 18 张表的变化，任何用户修改数据后，服务器立即推送变更事件
自动刷新：其他在线用户的 App 收到推送后，300ms 内自动刷新对应模块的数据
全局通知：数据变更同时触发右上角弹窗通知 + 操作日志记录（修改人、时间、内容）

协同场景示例

场景操作者其他用户看到
新增宾客「张三」 管理员 A 在电脑端操作 管理员 B 手机端 0.3 秒后宾客列表自动出现「张三」+ 右上角通知弹窗
修改流程时间 管理员 A 修改接亲时间 09:00→08:30 所有人流程页面自动更新 + 通知「A 修改了流程时间」
登记礼金 管理员 A 录入红包 1000 元 其他管理员收到通知 + 礼金总额自动更新
查看排班 普通成员打开车辆排班 看到最新排班信息，但无法修改（权限控制）

权限体系

角色可操作不可操作
admin（管理员） 所有模块增删改查、用户管理、系统设置 -
viewer（普通成员） 查看所有模块数据 礼金记账、用户管理、操作日志、系统设置（隐藏入口）
💡 关键点：无论用户使用电脑 PWA、桌面 Electron、还是安卓 APK，只要登录同一套账号体系，连接同一个 Supabase 数据库，数据就自动实时同步。不需要额外的服务器或中间件。
